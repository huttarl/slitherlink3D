# Slitherlink3D
Play slitherlink on a polyhedron, in your browser.

## Status
It's playable, but still under development.
Try it at https://huttar.net/lars-kathy/puzzles/slitherlink3D/main.html.

## Description
### Todo: convert links to markdown-style
I like Slitherlink puzzles, especially when <a href="http://krazydad.com/tablet/vslitherlink/?kind=penrose_lg_d2&volumeNumber=1&bookNumber=1&puzzleNumber=6">played on a variety of grids</a>.
But I would like to go beyond the flat page and the planar grid, to playing on a topologically spherical grid, such as a <a href="http://www.georgehart.com/sculpture/roads-untaken.html">polyhedron</a>. For aesthetic reasons as much as anything.

This project provides polyhedral grids, and a GUI in which to display them and let the user interactively
solve them.

Three.js is used to for the 3D display and input.
